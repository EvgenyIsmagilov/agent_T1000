# Морфология и работа с семантическим ядром (RU)

Читай этот файл, когда работаешь с семантическим ядром на русском (или украинском):
чистка, дедупликация, группировка запросов, нормализация словоформ. Это в первую
очередь про **Яндекс и рунет** — русский язык флективный, и без лемматизации ядро
раздувается дублями. Для англоязычного Google морфология почти не нужна (стемминга
хватает), но эти же инструменты применимы.

## Зачем это нужно

Один смысл в русском порождает десятки словоформ:
`купить телефон`, `куплю телефоны`, `покупка телефона`, `телефон купить` — это один
кластер намерения, но в выгрузке Wordstat/Key Collector они лежат отдельными строками.

Лемматизация (приведение к начальной форме) решает три задачи:
1. **Дедупликация** — схлопнуть словоформы одного запроса.
2. **Группировка** — собрать фразы с общим смыслом по общим леммам.
3. **Нормализация** — единый ключ фразы для сравнения и джойнов между источниками.

## Инструменты

| Библиотека | Что это | Когда брать |
|---|---|---|
| **pymorphy3** | Словарный морфоанализатор RU/UK, оффлайн, быстрый. Продолжение заброшенного pymorphy2 | Дефолт. Массовая обработка ядра |
| **pymystem3** | Обёртка над Yandex MyStem | Когда нужно контекстное снятие омонимии (`стекло` — сущ. или глагол?) |
| **natasha** (razdel/slovnet) | Современный NLP-стек RU | Если нужен более сложный NLP: NER, синтаксис |

Не тащи `pymorphy2` — он не поддерживается. Бери `pymorphy3`.

### Установка

```bash
pip install pymorphy3                 # основной бэкенд
pip install pymystem3                 # опционально: MyStem (качает бинарник при 1-м запуске)
pip install pymorphy3-dicts-uk        # опционально: украинский словарь
```

Перед первым использованием скрипта проверь наличие `pymorphy3`
(`python3 -c "import pymorphy3"`). Если нет — предложи пользователю установку, не падай молча.

## Бандл-скрипт: scripts/semcore.py

Готовый CLI. Вход — файл с фразами (одна на строку) или stdin. Все подкоманды
работают и с `--mystem` (бэкенд MyStem вместо pymorphy3).

```bash
# Леммы каждого слова (диагностика)
python3 scripts/semcore.py lemmatize keys.txt

# Фраза → нормализованный ключ (значимые леммы без предлогов/союзов)
python3 scripts/semcore.py normalize keys.txt

# Схлопнуть дубли-словоформы (в stderr — сколько убрано)
python3 scripts/semcore.py dedup keys.txt > keys_unique.txt

# Кластеризация по общим леммам (порог — сколько лемм должно совпасть)
python3 scripts/semcore.py cluster keys.txt --min-common 2

# С контекстным разбором MyStem
cat keys.txt | python3 scripts/semcore.py cluster --mystem
```

Скрипт выкидывает служебные части речи (предлоги, союзы, частицы, междометия)
по разбору бэкенда плюс страховочный стоп-лист. Значимыми считает слова длиннее
одного символа.

## Кластеризация: два подхода — не путай

- **Лемма-кластеризация (этот скрипт)** — быстрый оффлайн-препроцесс. Группирует по
  пересечению лемм. Хорошо для черновой разбивки ядра на направления и для дедупа.
  Дёшево, но не знает, как реально ранжируется выдача.
- **SERP-кластеризация (hard/soft)** — эталон для коммерческого SEO. Фразы в одну
  группу, если у них пересекается ТОП-10 выдачи (hard — по всем, soft — по ядру
  группы). Требует съёма выдачи через API (в рунете — Yandex XML/`yandex-search-mcp`
  или сервисы вроде Key Collector, Rush Analytics). Лемма-группировка её **не заменяет** —
  используй как первый грубый проход, затем уточняй по SERP там, где важна точность.

Практика: сначала `dedup` → потом `cluster` для черновых групп → затем SERP-проверка
спорных кластеров.

## Типичный поток

1. Выгрузить фразы (Wordstat/`yandex-wordstat-mcp` для Яндекса, Keyword Planner/GSC для Google).
2. `normalize` — привести к ключам, сджойнить частотности разных источников по ключу.
3. `dedup` — убрать словоформенные дубли, суммируя частотность.
4. `cluster --min-common 2` — черновые группы под страницы/кластеры контента.
5. Спорные группы уточнить по пересечению выдачи (SERP).
6. На каждый кластер — своя посадочная; внутри кластера собрать LSI/словоформы для текста.
