# SEO под Яндекс

Читай этот файл для работы под Яндекс и рунет. Яндекс ранжирует иначе, чем Google —
не переноси google-практики слепо. Про морфологию и кластеризацию ядра см.
`morphology.md` (для русского это обязательный этап).

## Инструменты и деградация

Навык гибридный: используй API/MCP, если настроены; иначе — ручные проверки. Никогда
не выдумывай частотность, позиции или трафик — нет источника, так и скажи.

| Задача | Инструмент (авто) | Fallback (руками) |
|---|---|---|
| Частотность, спрос, тренды | Yandex Wordstat API (`yandex-wordstat-mcp` из `yandex-tools-mcp`) | wordstat.yandex.ru |
| Индексация, позиции, диагностика, регион | Yandex Webmaster API (`yandex-webmaster-mcp`) | Вебмастер веб-интерфейс |
| Поведенческие факторы, трафик | Yandex Metrika API (`yandex-metrika-mcp`) | Метрика веб (Вебвизор, карты) |
| Выдача, SERP-съём | Yandex Search API (`yandex-search-mcp`, XML) | руками; операторы `site:`, `host:`, `url:` |
| Контекст (PPC) | Yandex Direct API (`yandex-direct-mcp`) | Direct веб |

Доступ к Wordstat API запрашивается отдельно и требует `YANDEX_SEARCH_API_KEY` +
`YANDEX_FOLDER_ID`. Нет ключей — работай через веб-Wordstat и объясни пользователю,
что подключить.

## Что ценит ранжирование Яндекса (и чем отличается от Google)

- **Поведенческие факторы (ПФ) — вес выше, чем в Google.** CTR в выдаче, отказы,
  глубина просмотра, время на сайте, возвраты в выдачу (pogo-sticking). Ядро оценки —
  насколько пользователь доволен. Метрика напрямую кормит эту оценку.
  ⚠️ **Накрутка ПФ — прямой путь под фильтр** с обнулением трафика. Не предлагай и не
  используй сервисы накрутки; вместо этого улучшай реальный UX и сниппеты.
- **Региональность — сильнее, чем в Google.** По геозависимым запросам выдача своя для
  каждого региона. Регион привязывается в Вебмастере; для мультирегиональности —
  поддомены или папки на регион с уникальными контактами/ассортиментом.
- **Коммерческие факторы (для коммерции).** Ассортимент, цены, способы оплаты и
  доставки, контакты, отзывы, онлайн-консультант, юр. инфо — Яндекс прямо оценивает
  «качество» коммерческого сайта.
- **ИКС** (Индекс качества сайта, заменил тИЦ) — интегральная оценка полезности;
  ориентир, не прямой рычаг.
- **Нейросети в ранжировании** (YATI и далее) — семантика и соответствие смыслу
  запроса, а не вхождения. Плюс нейро-ответы Яндекса в выдаче (см. GEO ниже).
- **Ссылки** работают, но осторожно: покупные SEO-ссылки → риск Минусинска. Упор на
  естественность и тематичность.

## Фильтры Яндекса — чего избегать

- **Баден-Баден** — переоптимизация текста (переспам ключами, «SEO-тексты для робота»).
  Пиши для людей, естественная лексика, без простыней с вхождениями.
- **Минусинск** — за покупные SEO-ссылки.
- **АГС** — малополезные сайты, дорвеи, тонкий контент.
- **Фильтр за накрутку ПФ** — за имитацию поведения.

## Технический аудит — что специфично для Яндекса

Общая техбаза совпадает с Google (см. `google.md`: sitemap, canonical, коды ответов,
скорость, ЧПУ). Отличия и акценты Яндекса:

- **`robots.txt` — `Clean-param`.** Директива Яндекса: склеивает URL с незначащими
  GET-параметрами (utm, сортировки, сессии), экономит краулинговый бюджет и убирает
  дубли. Это специфика Яндекса — Google её не понимает (для Google — canonical/параметры).
- **Устаревшее:** `Host` (отменён в 2018 — не используй, склейка зеркал в Вебмастере) и
  `Crawl-delay` (отменён — скорость обхода настраивается в Вебмастере).
- **Вебмастер:** переобход важных страниц вручную, «Оригинальные тексты» для защиты
  авторства перед публикацией, мониторинг ИКС и диагностики, привязка региона.
- **Зеркала и главное зеркало** (www/без, http/https) — настраиваются в Вебмастере.

## Семантика под Яндекс — Wordstat

Операторы Wordstat (уточняют, что именно считаем):

| Оператор | Смысл |
|---|---|
| `слово` | широкое: все запросы со словом в любых формах + вложенные (базовая частота) |
| `"фраза"` | фиксирует состав фразы (словоформы внутри допустимы, без хвостов) |
| `!слово` | фиксирует конкретную словоформу |
| `"!точная !фраза"` | точная частота: и состав, и формы |
| `+` | учитывать стоп-слово/предлог (Wordstat их по умолчанию игнорирует) |
| `-минус` | исключить слово |
| `слово1 \| слово2` | или |
| `(группировка)` | скобки для сложных условий |

Три частотности принято снимать: базовую (`слово`), фразовую (`"..."`) и точную
(`"!..."`) — разрыв между ними показывает, насколько запрос «размазан» по словоформам
и хвостам.

Поток: собрать из Wordstat (левая колонка — что ищут со словом, правая — что ещё ищут
эти люди) → **лемматизировать и кластеризовать** (см. `morphology.md`, `scripts/semcore.py`)
→ разметить интент и коммерческость → уточнить спорные кластеры по пересечению выдачи
(Search API / съём ТОПа) → распределить по посадочным.

### GEO — нейро-выдача Яндекса

Яндекс отдаёт нейро-ответы (сжатая выжимка по запросу). Для попадания в них — те же
приёмы, что и для AI Overviews Google: прямой ответ в начале, фактурность, структура
(списки/таблицы), ясность сущностей. См. GEO-раздел в `google.md`.

## On-page под Яндекс

- **Title** — ключ ближе к началу, читабельно, без переспама; учитывай регион для
  геозапросов.
- **Description** — Яндекс часто формирует сниппет сам (из текста/разметки), но
  description влияет; держи релевантным и «кликабельным».
- **Текст** — естественный, закрывает интент; **бойся Баден-Бадена** — никаких
  простыней ключей. Словоформы и LSI бери из лемматизации ядра, вплетай естественно.
- **Разметка** — Schema.org (Organization, Product, отзывы, хлебные крошки); отзывы и
  рейтинги усиливают коммерческие факторы и сниппет.
- **Коммерческий блок** — цены, наличие, доставка, контакты с регионом, онлайн-оплата.

## Метрики и мониторинг

- **Позиции** — Вебмастер («Мониторинг запросов»), с учётом региона; съём по регионам,
  если проект мультирегиональный.
- **Индексация** — Вебмастер: страницы в поиске, исключённые и причины.
- **Поведенческие** — Метрика: отказы, глубина, время, Вебвизор (запись сессий),
  карта кликов/скроллинга — чинить реальные проблемы UX, влияющие на ПФ.
- **ИКС** — динамика в Вебмастере.
- **Трафик по регионам и устройствам** — Метрика (сегменты).

## Связка с Google

Если проект под рунет, техбаза общая с Google — веди аудит один раз, а семантику,
регион, поведенческие и коммерческие факторы дорабатывай под Яндекс отдельно.
Разделяй отчёты и рекомендации по движкам (этого прямо просит пользователь навыка).
